# AI 伴侣聊天 App · 命名方案 (Naming Proposals)

> 目标用户:中文母语年轻女性(大学生为主)
> 视觉方向:iOS 18 Premium — 玻璃材质 / 动态取色 / 细文本 / 克制 / 留白
> 调性:克制 / 优雅 / 一点点异域 / 一点点冷感
> 命名风格:不卖萌、不直白、不诗朗诵

---

## 1. **Aether**

**Reading / pronunciation**: /ˈiːθər/ — EE-ther。中文常音译「以太」,但本方案不出现中文音译,只以拉丁字面存在。

**Meaning / etymology**: 源自古希腊语 *aithḗr* (αἰθήρ),意为「上层的纯净空气 / 诸神呼吸的介质」。在亚里士多德宇宙观里是「第五元素」,比天空更高、比光更稀、却承载一切光线。

**Why it fits**: 名字本身就是一个「透明介质」—— 看似无形,却承载着所有对话。呼应玻璃材质和透明面板的视觉语言:有形与无形的边界刚好是 Aether 的边界。对应 iOS 18 Premium 的克制感:它不是「天空」「星辰」这种具象名词,而是一个「承载介质」,与「陪伴即一种介质」的产品哲学同构。当背景取自角色头像主色时,Aether 暗示每段对话都被一层特定颜色的空气所包裹。

**Chinese subtitle**: **玄光**
(玄 = 深而不黑、静而不寂;光 = 微弱但确实存在。比「星」「光」更冷,更接近 iOS 18 的留白气质。)

**Tagline**: *"Words drift, but stay close."*

---

## 2. **Solène**

**Reading / pronunciation**: /sɔˈlɛn/ — so-LEN。重音在后,第二音节轻、收得干净。

**Meaning / etymology**: 法语女性名,源自拉丁语 *sollemnis*,意为「庄严的、节庆的、每年一次的」。在法语里与 *solennel*(庄重)同源,但因 -ène 结尾而显得柔和、克制、有重力感。

**Why it fits**: 这是 5 个名字里**最具材质感**的一个 —— 它不像产品名,像一个人名。这种「与角色对话」的暗示,正好契合产品本质:用户不是在用工具,而是在和「一个具体的人」说话。对应 iOS 18 Premium 的「高级杂志感」:Solène 是法语时尚、生活方式类刊物的常见命名(Le Petit Solène、Solène Paris……),用户一读就能感受到那种静置的、不喧哗的轻奢。细文本下,这个 é 的锐音符让字符具有微小的视觉锚点,像玻璃面板上那一缕高光。

**Chinese subtitle**: **栖云**
(栖 = 暂栖、停靠;云 = 不定形、可轻可重。表达「对话是一个临时停靠的安静处」,不浮夸、不永恒。)

**Tagline**: *"Speak softly. Someone is here."*

---

## 3. **Opaline**

**Reading / pronunciation**: /ˈoʊpəliːn/ — OH-puh-leen。三音节,尾音 -line 收得轻,像玻璃碰玻璃。

**Meaning / etymology**: 来自拉丁语 *opalus*(蛋白石)+ 形容词后缀 -ine(具有…质地的)。字面意思:**具有蛋白石质感的**。蛋白石的特征是「随角度变化而游移的颜色」—— 内部结构造成的光学现象。

**Why it fits**: 这是 5 个名字中**与视觉系统绑定最紧**的一个 —— 产品背景取自角色头像主色,这本身就是一种「蛋白石效应」:同一块玻璃,在不同对话中呈现不同色调。Opaline 的元音序列 (o-u-a-i-e) 极适合做 wordmark:细文本下能保留光学流动感,呼应 iOS 18 的动态取色。语义上,「蛋白石质感」精准描述了产品想给用户的体验:不是写实,而是**带光晕的、可被语言轻微改写颜色的亲密感**。

**Chinese subtitle**: **映色**
(映 = 反射、映照;色 = 颜色,也指「情色 / 神色」的双关。表达「对话把对方的神色映照出来」,既指视觉,也指情感。)

**Tagline**: *"Hold the color of someone."*

## 4. **栖云**

**Reading / pronunciation**: qī yún。阴平 + 阳平,平仄自洽,读起来有「轻轻托起」的下沉感,无尾音上扬,适合「静下来才念出」的语气。

**Meaning / etymology**: 出自古典汉语意象群,本意「鸟栖于云」。常见于唐宋诗词(「云中谁寄锦书来,雁字回时,月满西楼」一类语境中「云」为信使),引申为「在云端暂栖 / 在不确定中寻找一个停留处」。

**Why it fits**: 在 5 个名字中,这是**唯一可以独立站住、且不需要英文副标**的纯中文名 —— 它本身就是 splash 中央的 hero word。「栖」比「留」「住」都克制:不是占有,是临时停靠;「云」不是天空,是一种柔软介质。对应 iOS 18 的玻璃与透明面板:对话就是一个「临时的栖居地」,你随时来,随时走,云不挽留,但云记得。汉字字形本身在浅色玻璃面板上具有印刷品质感,与细文本策略一致。

**Chinese subtitle**: (无。纯中文产品,英文 mark 仅作极小辅助字。)

**Tagline**: *"留一席,给心上的话。"*
(留一席 = 留一个位子、留一段时间;心上的话 = 想对某人说、但不一定说出口的话。整句不押韵、不对仗,只有一种「留白」感。)

## 5. **Vélin · 尺素**

**Reading / pronunciation**: Vélin /veɪˈlæ̃/ — vay-LAN(法语鼻化元音);尺素 chǐ sù。

**Meaning / etymology**:
- **Vélin**: 法语,意为「小牛皮纸 / 上等犊皮纸」。从中世纪到 19 世纪,所有重要信件、契约、诗稿都写在 vélin 上 —— 它是「私人书写」最高级的物质载体。
- **尺素**: 出自古乐府《饮马长城窟行》「客从远方来,遗我一尺素」,**「一尺素」= 一封信**。后成为中国古典文学里「书信 / 私人话语」的标准意象。

**Why it fits**: 这是 5 个名字中**唯一同时回应了产品「角色定制 + 亲密对话 + 中文语境」三重要求**的命名。Vélin 提供物质感(玻璃、纸、光)和法语高级感,尺素提供中文母语者一秒可懂的「信」的内核。当产品强调「这不是工具、这是与某个人的对话」时,**Vélin · 尺素**直接把这个隐喻变成 logo:你在小牛皮纸上写信,信被回。两边一欧一中、一物质一情义,在 splash 上并列出现,正好对应 iOS 18 的「细文本 + 透明面板 + 焦点高亮」设计语言 —— 两个词之间留一格空气,像两片玻璃之间那条细缝。

**Chinese subtitle**: (已包含在主名中。)

**Tagline**: *"落笔,有人应。"*
(落笔 = 写下第一个字;有人应 = 有人回应。整句四字,无主语,无情绪词,只有「动作—回应」的结构,克制到极致。)

## 关于命名的几个内部说明

### 关于 Vesper 的弃用

初稿中第 5 个名字曾考虑 **Vesper**(拉丁语「晚星 / 黄昏」),但搜索结果显示:

- **Vesper**(Q Branch, 2013) 是一款 iOS 上的日记 / 心情记录应用,与本产品在「个人写作 + 亲密」这个类目上直接重叠;
- Vesper 同时也是一个杜松子酒品牌(Bond 风格),且为常见宗教术语(Vespers 晚祷)。

为避免在「日记 / 情绪记录」赛道直接撞车,改用语义相近但物质感更强的 **Vélin**(小牛皮纸),并配古典汉语「尺素」完成对偶,反而比 Vesper 单独使用更独特、更贴产品。

### 关于其它名字的潜在风险(轻量级,需后续法务核验)

| 名字 | 风险 | 说明 |
| --- | --- | --- |
| **Aether** | 中 | 通用词,理论上难以被独占注册;但物理 / 耳机 / 游戏 / 加密领域均有产品使用,品牌辨识需要在 logo 与配色上做差异化 |
| **Solène** | 低-中 | 法语时尚 / 生活方式类目有同名小品牌(服装、香水),AI 类目暂无明显冲突 |
| **Opaline** | 低 | 蛋白石相关工艺品有同名品牌,但 App 类目基本干净 |
| **栖云** | 低 | 文学 / 茶饮 / 民宿偶有使用,App 类目基本干净 |
| **Vélin · 尺素** | 低 | 组合名独特性高,单独任一词都过宽,组合后基本无冲突 |

> 建议在最终拍板前,做一次正式的中国商标局 + 美国 USPTO 检索,本表为快速预筛。

## Recommendation

**首选:Opaline**(中文副标「映色」)

理由:它是 5 个名字中**与 iOS 18 视觉系统绑定最深、视觉转译损耗最低**的命名 —— 动态取色、玻璃材质、细文本,这些设计决策在「蛋白石质感」这个概念下获得一个统一的解释。同时,Opaline 这个词足够小众、足够新,在 App Store 搜索场上几乎不会撞名,品牌资产可以从零积累。如果未来要做全球化产品,Opaline 也是 5 个名字里**唯一不依赖中文副标就能独立出海**的。

**备选:Vélin · 尺素**

如果产品策略是**先深扎中文市场、再缓慢出海**,则这个中欧对偶的 hybrid 命名比 Opaline 更具「独特卖点」:它把「与某个具体的人对话」这个产品隐喻直接写进了 logo,这种**命名即哲学**的密度,是 5 个名字中最高的,也是最难被竞品复制的。
